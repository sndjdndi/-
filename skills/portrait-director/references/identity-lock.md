# Identity Lock

Use identity preservation as a structural constraint, not a vague prompt such as "same face".

## Build the lock list
Record visible identity-bearing traits from the source: overall face silhouette; forehead and hairline; cheek width; jaw angle and chin; eye spacing/shape; brow placement; nose bridge/tip/width; philtrum; lip contour and mouth width; ear placement when visible; distinctive asymmetries or marks.

Separate identity from transient appearance. Makeup, skin tone grading, hair flyaways, lighting, and temporary shadows may be edited without redefining facial geometry.

## Reference hierarchy
- source portrait = identity authority
- pose reference = pose only
- lighting reference = light only
- composition reference = framing only

Never let the face in a pose or lighting reference replace the source identity.

## Drift indicators
Reject or revise when the result changes jaw width, eye spacing, nose structure, mouth contour, age impression without request, or characteristic asymmetry enough to read as another person.
