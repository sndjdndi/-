# Style Profile

Use this reference when the portrait request is style-sensitive.

## Preferred portrait finish
- realistic photographic portrait
- soft but clear light
- visible hair strands
- realistic skin texture
- clean blacks and clear tonal separation
- no gray haze and no washed-out look
- premium commercial/editorial finish

## Common user dislikes
- face shape changed without permission
- pose, mouth movement, expression, or small gestures changed
- anime-like face or doll-like skin
- over-smoothed skin
- fuzzy detail and jagged edges
- four options that are actually four different people

## Default 4-panel labels
Use short labels such as:
- 清新柔和
- 光影质感
- 发丝细节
- 线条微调

Keep labels brief and visible.
