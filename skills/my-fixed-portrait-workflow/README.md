# 我的固定人像流程

这是用于固定人像改图、锁脸、四图小幅变化、Adobe 精修和 Magnific 高清增强的个人 Skill。

## 常用触发语

- 按我的固定人像流程处理这张图。
- 按我的固定人像风格修改这张图，脸型不要变。
- 锁脸，先出 4 张小变化版本给我选。
- 我选好了，用 Adobe 精修这张。
- 继续用 Magnific 保守高清增强。

## 核心规则

- 参考脸优先级最高。
- 默认保留原构图、动作和已喜欢的元素。
- 默认只做小变化，不大改。
- 禁止明显动漫化、二次元化和塑料感。
- 身材优先级：脸 > 胸 > 腰 > 臀 > 腿。
- 默认先给 4 张小变化候选，用户选定后再精修。
- Adobe 用于精修；Magnific 用于最后的保守高清增强。

详细规则见 `SKILL.md` 和 `references/style-profile.md`。
